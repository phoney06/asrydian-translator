ASRYDIAN LIVE TRANSLATOR

Open index.html while connected to the internet.

The website loads this Google Sheet tab each time it opens or refreshes:
MASTER DICTIONARY

Live CSV endpoint:
https://docs.google.com/spreadsheets/d/1G_9jYq_G88jC6eUKOyz8hSekGLLuVrwRAPSQQ-UGnmE/gviz/tq?tqx=out:csv&sheet=MASTER%20DICTIONARY

Updating:
1. Add or edit a row in the MASTER DICTIONARY tab.
2. Wait a few seconds for Google Sheets to save.
3. Refresh the translator webpage.

The Google Sheet must remain shared as:
Anyone with the link — Viewer

To give other people a normal public website link, upload index.html to a static host such as GitHub Pages, Cloudflare Pages, or Netlify.
